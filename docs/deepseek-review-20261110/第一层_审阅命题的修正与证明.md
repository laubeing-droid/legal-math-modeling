# 第一层：审阅命题的修正与证明

本稿补正审阅稿自身的数学陈述，原审阅稿保留。全景边界与主链采用《第一层_统一法律数学模型_修订》；这里不给工程状态替代证明。

## 1. 事件、共同模型与条件化（D1—D4）

**事件身份。**设记录到 occurrence 的映射为 τ:R→E，有限记录 D 的事件数定义为 |τ(D)|。若 τ(r)∈τ(D)，则 τ(D∪{r})=τ(D)，计数不变；空 D 的计数为 0，不能无条件写成 1。历史追加使用 fresh∉tokens(h)，旧历史为新历史前缀。若 h++[x]=h′++[x′]，反转并对列表头尾取等，得 h=h′、x=x′；不需要 fresh 本身对所有历史单射。

**密度条件化。**设 Π 是世界概率律，L(ω,z)≥0 联合可测，且对 Π-a.e. ω 有 ∫L(ω,z)ν(dz)=1，ν 为 σ-有限基准测度。令 q(z)=∫L(ω,z)Π(dω)。Tonelli 给 ∫q dν=1，故 q<∞ ν-a.e.，且 P_Z(dz)=q(z)ν(dz)。在 0<q(z)<∞ 处，Π_z(dω)=L(ω,z)Π(dω)/q(z) 是概率律，并由积分直接验条件化等式；其余位置任取一个固定概率律，不能据此声称已经取得不可识别的外部核。

这里 {q=0} 是 P_Z-零集，未必 ν-零集。取 ν 为 [0,1] Lebesgue 测度，L=2·1_[0,1/2]，则 ν(q=0)=1/2。共同 σ-有限密度也不是一般观测的自动性质：若 Z=ω、ω 连续，条件律族 δω 若全由同一 σ-有限 ν 控制，就要求每个单点 ν({ω})>0；σ-有限测度只能有可数个正质量原子，矛盾。无密度时应直接使用正则条件分布的适用条件。

**共同视图。**令 v:Ω→S 可测，Γ⊆S 可测，且 v(ω)∈Γ 对 Π-a.e. ω 成立，则 v#Π(Γ)=Π(v⁻¹Γ)=1。不能无条件把可能不可测的像集 v(Ω) 直接放进概率式；也不能把各视图的边际任意相乘。Γ 非空须由共同见证给出，不能以空域完成全称判断。

**索引与路径。**固定 (λ,m) 得一条 Kλm 路径律族；变化时把索引及其给定更新并入状态。对每个 λ 单独可测不够：取非 Borel A⊆[0,1]，令 Kλ(s)=δ_(1_A(λ))。每个 Kλ 关于 s 都是常核，而可测选择 ρ(s)=s 给 Kρ(s)(s,{1})=1_A(s)，不是核。若族联合可测，状态依赖选择仍是一个自治核；只有真正外生按 n 变化时才是 K_n 的非自治序列。

## 2. 主体可用信息、许可与识别（D5—D7）

**因子化。**非空标准 Borel 目标空间上的 Doob–Dynkin 判据为：f 对 σ(obs) 可测，当且仅当 f=g∘obs，g 可测。反向由可测复合；正向由标准 Borel 因子化定理。由此可得相同可用观察、相同私人参数时，策略及实际学习更新相同。若只证在较细的 actual 观察上，不能推较粗的 use 观察：X={0,1}，actual=id、use 恒定，f=id 即反例。新取得的行动／结果也必须进入真正的可用观察，不能保留一个未取得的隐藏原始结果旁路。物理结果 Q 可以依赖未知世界；这一点本身不构成主体读取隐藏世界。

**许可截断。**给定可测许可图 A(s)，若 π_s(A(s))>0，则 π^perm_s(B)=π_s(B∩A(s))/π_s(A(s)) 的总质量及许可质量均为 1；联合可测条件保证它仍是核。零质量时须另有可测合法默认行动，或返回没有可执行行动。A(s)=∅ 时不可能存在支撑其中的概率律，不能无条件指定“等待”。

**识别。**Ξ^a_s(dω,de)=Π_s(dω)T(s,a,ω;de) 的 e-边际 QΞ 按定义可求。Qactual=QΞ 仅在 A-IDENT 成立时使用。W~Bern(1/2)、Y=W，保留 S=Y=1 的样本，则 Qactual=QΞ=Bern(1/2)，Qobserved=δ1；错误是把筛选样本外推到未筛选通道。观察他人选择行动时，选择本身可能提供世界信息，须使用相应选择似然而非直接当干预。

## 3. 延迟、学习更新与路径不变量（D8—D11）

**固定延迟。**用 L 个 oldest-first pending 格，当前转移先读取头格完成项、再移位并放入新项。第 t 次转移入队的项，在第 t+L 次转移被读取；该次输出状态编号为 t+L+1。未完成用 none 表示，学习 U(θ,none)=θ；不是零标签。状态含队列及原完整历史后，下一步只读当前状态，因而为 Markov。若删掉 pending，两个其余摘要相同、头格分别为 0/1 的状态下一学习值不同，便不能由删减摘要的同一个确定更新表示。完整历史原本包含任务信息时，一般一步式当然可以表示延迟；“出现未来形式参数即不可能”是错误断言，常函数已是反例。

**一次 Beta 预测。**q∈(0,1)、κ>0，先验 Beta(κq,κ(1−q))，观察 Bernoulli 成功 Y 后，后验参数为 κq+Y、κ(1−q)+1−Y，所以后验均值为 (κq+Y)/(κ+1)。它是学习率 1/(κ+1) 的一次平滑；失败数必须是 1−Y。κ=1 时的 Beta(q,1−q) 不均匀。每轮重置这个先验得到的固定率平滑，不是固定隐变量的完整多轮 Bayes：q=1/2 连续成功两次，前者 7/8，固定 Beta(1/2,1/2) 的后验预测是 5/6。q=0/1 不能直接套正参数 Beta 定理。

**路径保持。**可测 I、μ0(I)=1，且每个 s∈I 有 K(s,I)=1，则 μ_(n+1)(I)=∫K(s,I)μ_n(ds)=1；归纳并取可数交得 P(∀n,S_n∈I)=1。指定行动安全不足：均匀抽取两个行动，其中一个离开 I，则 K(s,I)=1/2。对无关参考律几乎处处闭合也不足：I={0,1}，参考律 δ0，K0=δ0、K1=δ2，实际初态 δ1 下一步离开 I。

**摘要。**若 T:S→Z 可测，且 K(s,T⁻¹B)=K̄(Ts,B) 对所有 s、可测 B 成立，则 T#(μK)=(T#μ)K̄；证明将两边在 B 的核积分直接比较，有限步归纳同理。判断／许可／效果还须分别经 T 因子化。余额相同但程序期限标记不同就是摘要不足的简单例，毋须引入错误的具体时效法律断言。原空间核与商空间核不能直接写成相等。

## 4. 稳定性与统计到决策（D12—D14）

本实例的三层结论、共同耦合、非退化不变律、几乎必然不收敛、方差 17/193 及最优常数 3/4 已在全景修订稿 §7.4 给出完整简证。路径反例取 p<U<p′，不是原稿写反的次序。

共同均匀耦合的精确期望不等于三角上界。令 Δθ=θ−θ′、Δp=p−p′，四格质量为 1−max(p,p′)、max(p′−p,0)、max(p−p′,0)、min(p,p′)。对 |Δθ|≤1，逐格算得 E d*′=(1−|Δp|)|Δθ|+3|Δp|+ΔpΔθ。Δx=.8、Δθ=−.1 时，精确值 .52，而原三角式为 .55；两者都满足 3/4 界，不能把上界称为精确值。

两个边际最优运输代价之和通常只给联合 W1 的下界。μ=½δ_(0,0)+½δ_(1,1)、ν=½δ_(0,1)+½δ_(1,0) 的两个边际相同，但 d* 联合 W1=1：每个源点到最近目标点距离为 1，并有成本 1 的显式共同配对。修订数值检验保留每个完整 (x,θ) 样本再配对，得到合法上界。

非线性均值不自动交换，且确定性收缩不自动给随机均值收缩，闭合域反例见全景 §10。由条件均值进一步写 E F(Z)=F(EZ)，还需仿射等交换条件。

**真正校准也不够。**四类样本 (行动,预测,质量,真实成功率) 为
(0,2/5,3/10,2/3)、(1,2/5,1/5,0)、(0,3/5,1/5,1)、(1,3/5,3/10,1/3)。逐预测分组的真实率恰为 2/5、3/5，确实校准；但两个行动的真实值为 4/5、1/5，平均预测为 12/25、13/25，排序反了。因此决策误差传递应使用逐行动界，不能偷换成平均校准。给 |V̂(a)−V(a)|≤η，且 V̂(â)≥sup V̂−ε，依次夹逼两次就得 V(â)≥sup V−ε−2η；唯一最优间隔大于 2η 时，精确贪心选择保持最优。

即使 TV(Qa,Qb)=0，反馈也未必相同：Qa=Qb=δ0，Ma≡0、Mb≡1。应比较反馈推前 Ra=(Ma)#Qa；若再要求 Ma=Mb 才能直接由原结果律比较运输。相同分布也不等于同一次 occurrence，要保留实际共同抽样。

## 5. 业务表示与全模型边界（D15—D16、F13—F14）

设 β:B×C→B 为原实际推进，enc:B→S 有左逆 decode，并且对实际共同输入 c 有 enc(β(b,c))=Φ(enc(b),c)。有限串交换由长度归纳；原不变量沿 β 保持，便在解码的实际 Φ 后态上保持；读数 rS∘enc=rB 则同样交换。若 κ_b 是同一输入律，可测推前给 enc#[(β(b,·))#κ_b]=[Φ(enc b,·)]#κ_b。没有同一输入律，仅点态交换不足：β(b,c)=c、Φ(s,c)=c，分别输入 δ0、δ1 就给不同后态律。无忠实表示／纤维可表示性时，也不能把任意原状态性质强行降到摘要。

构造保留原完整输入历史与实际后态的忠实表示，有效性在于原推进 β 及其读数均被保持。具体实例的交换等式应从原实际推进推导，不能把待证等式本身当作该实例的独立假设。

四面仍是法律实体、具体法律制度、法律运行、演进；统计条件贯穿相应概率声明。J/A/C 及六判断、四效果由同一历史和共同世界上的可测读数或关系表示，并分别保留各自取值。F13/F14 的准确义务是证明这些既有语义、制度转移、引擎结果和演进在相同输入／后态上相容；已有原理和现有制度证明不能抹掉，尚缺的逐实例交换也不能靠并排放置两个证明代替。一般收缩只是条件性更强结论，不是统一模型成立的必要定义。
