## 5. 本轮 Lean 精确范围与部分目标

- L1：OccurrenceHistory 的 fresh 不撞、append_injective、append_prefix、良构保持、record_count_once。计数用事件身份，不以记录条数替代。
- L2：ObservationBridge 保留 Dynamics 并新增 ObsDynamics；Doob–Dynkin、no_leak 与两个反例。不能从 actual 因子化推 use 因子化。
- L3：InvariantClosure 对每个不变量状态闭合；得到同一 pathLaw 上所有时刻保持，且已有原业务消费者。
- L4：DelayAugmentation 的 d+1 格 oldest-first 队列，原概率响应核经 numeric 取回；证明 t+d+1 时队首恰为 incoming(t)，并在该次转移用于学习、只用完成值学习及 Markov。反例限于删掉 pending 的摘要；不宣称一般 Dynamics 不能表示延迟。
- L5：FeedbackW1 的四格耦合，直接使用原 after／probability，证明 one_step_contraction；w1 是两点原始运输矩阵的 inf，不是两个边际最小代价相加。一般分布 primal 值另定义为 distributionW1。
- **L5 partial 目标**：twoAtomIdentificationTarget（矩阵 inf 与一般 couplingMeasures inf 的形式化相等）；generalW1LiftTarget（对任意方形上概率律的可测耦合提升）；uniqueInvariantLawTarget（方形上的唯一不变概率律）。固定 Mathlib 版本源码中没有 Wasserstein／Kantorovich 定义或相应完备性 API；需要建立该代价度量、完备性及提升定理，不能用普通 Banach API 直接假装已有概率律度量。第一层已给完整数学证明；Lean 中明确是 Prop 目标，没有作为前提喂给其他定理。
- L6：BusinessTransport：忠实表示与同一输入律的运输，具体 O1—O5 均有落点，原 observation event 身份计数及业务路径不变量确实消费新证明。
- L7：UnifiedChainAudit 显式列出原关键目标；Review20261110.Audit 是新 driver。原 53 目标从来不缺运行输出；增加直接打印是可读性改进。根入口只在新模块单独构建 pass 后加入。

固定延迟已证明不等于可变延迟、永不完成和修订的全部理论已证明。分布稳定性的 partial 不牵连已证的均值几何界、路径边际、业务闭环与训练—收益总定理。
