# Forbidden Claims

The repository does not support the following statements:

- the entire juris-calculus system is formally verified by Lean;
- Python or a deployed runtime is generally refinement-proved against every Lean model;
- passing three fixtures proves all legal or operational cases;
- a green GitHub workflow is sufficient without reading the evidence contents;
- an axiom audit, theorem count, test, hash, receipt, paper, or report is itself a proof of legal correctness;
- Horn-to-AAF translation is globally complete and creates no spurious attacks beyond the stated bounded contract;
- production proof traces have a universally sound independent checker;
- incremental grounded computation equals full recomputation in all cases;
- Banach, privacy, empirical calibration, OCR correctness, or legal-source completeness is established unless a specifically cited artifact proves that exact proposition;
- the latest documented release run certifies later commits;
- finite-retention CI artifacts are a permanent evidence archive.

If required evidence is absent, stale, mismatched, skipped, timed out, or unavailable, the supported status is `UNKNOWN` or BLOCKED—not PASS.

See [Allowed Claims](ALLOWED_CLAIMS.md) for the narrower statements the evidence does support.
