## 冻结原题范围

冻结题单 `06_概率决策信息价值与策略.md` L113、L115、L117 要求：固定分支有限模型中比较无信息值与有信息值，明确原行动可选、信号可忽略且尚未扣成本；证明完美信息上界；给出含噪两状态净信息价值与购买阈值，其中 `k` 应包含采集成本和等待损失；并在多法律分支、无未经授权先验的稳健目标下，证明新信号策略包含旧策略且同一分支模型、无强制额外成本时最优值不下降。

## 已审声明

- `finite_conditional_value_of_information` 对任意有限 `Ω/Y`、PMF `P`、实值效用、非空有限行动集 `C`，使用实际 `PMF.map` 信号律与正信号纤维上的 `PMF.filter` 条件律，给出 `V₀ ≤ VY ≤ E[max_a u(a,ω)]`。条件律只在零质量信号处作总化；正质量分支按归一化过滤律计算。第一不等式来自原行动仍可作为忽略信号的常量策略，第二不等式为完美信息上界。
- `finite_robust_information_monotone` 对有限非空分支集、每分支实际 PMF/效用、同一非空行动集，要求每个旧常量行动策略都属于信号后策略集；因此信号后 max-min 值不低于旧 max-min 值。没有引入分支先验，结论不覆盖强制成本、行动集/风险约束变化。
- 原题 L115 的有限噪声二状态实例复用 U06.5 包的 `signal_joint_law` 与 `signal_information_values`：等先验、正确率 4/5，无信号值 1/2、有信号值 4/5，净增值 `3/10-k`，严格值得购买当且仅当 `k < 3/10`。此处 `k` 是应由问题输入的采集加等待总成本参数；本证明不从系统执行自动导出其实际数额，也不把准确率提升单独当净收益。
