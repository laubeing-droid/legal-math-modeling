`runProbability` checks the actual EventId partition, calls the existing finite empirical-risk minimizer, and passes its actual table to `produceInterval`. The table's query score determines an equal-score bin. Calibration labels in that bin determine success numerator Nhat, coverage Chat and empirical probability Nhat/Chat. The returned interval is

- lower = max(0, (Nhat-r)/(Chat+r));
- upper = min(1, (Nhat+r)/(Chat-r)), with Chat-r strictly positive.

Every model and every feature-index query in the predeclared family is counted: M = number of distinct candidate tables times feature width. The existing exact rational radius check verifies a sufficient bound for sqrt(log(4M/delta)/(2n)). Counting only the selected table's bins is refused when its numerical witness does not pay for the full family. Uniform control allows the fitted model and query to depend on the observed history, while the candidate family and population law remain fixed in the theorem.

`population_bin_integrals` identifies the indicator integrals with the actual measure of success within the score bin and the measure of that bin. `whole_pipeline_bin_probability_confidence` constructs one measurable event of probability at least 1-delta. On it, every successfully returned interval contains the selected bin's population conditional success probability, with positive population coverage. The theorem derives the required radius condition from accepted execution. It does not assume the desired population bound as an input.
