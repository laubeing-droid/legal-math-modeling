## 对象定义 v3（冻结条款全文）

设条件组：法域环境 J（含适用范围）、规范环境 V、证据状态 e、时点 t，及事件历史时间结构 H。

一、对象：法律关系整体状态 **B_t = (R_t, K_{e,t})**。R_t 为规范本体状态；K_{e,t} 为现有证据及证明规则下的认知/可支持状态集合。关系整体含共同约束（同一损失、竞合互斥、共同消减）。

二、真值与判断分层：Truth(q, R_t) ∈ {true, false} 为规范本体语义；Judgment(q | K_{e,t}, P, V) ∈ {成立, 不成立, 未决} 为给定证据、证明责任与程序状态下依法可支持的判断。**Judgment=不成立 ⇏ Truth=false**，除非规范另有构成效果。

三、求值：**Eval(q) = (Judgment(q), Disposition(q))**，q 分实体/程序/效力型；Disposition ∈ D ∪ {∅} 为程序法律效果字段，不与三值竞争；程序主张的确定 Judgment 不自动生成实体主张的 Judgment。原四值 Status 为展示层投影 Render。

四、事件与转移：有法律效果的事件依规范作用于 R_t，证据更新原则上作用于 K_{e,t}，同一事件作用二者须分别说明依据。裁判事件：**R_{t+1} = T(R_t, EffectType(JudgmentEvent))**，确认性裁判不得实现为创造关系，仅形成性裁判产生实体状态转移。

五、类型模态：**Power**（可以实施/产生法律效果）、**Obligation**（依法应当/不实施）、**Occurred Event**（事实上/法律上已发生）——三者互不推出（无一般性无条件蕴含，具体规范可建立条件性推导）。

六、规范选择：**ApplicableNorm = A(J, V, q, H, t)**，H 承载相关事实/事件时间结构；t 不单独决定版本。

七、未决条件：必要材料缺失且穷尽举证责任/推定/证明妨碍/程序终结规则仍不能判定时输出未决；证明失败的法律后果是合法结论。

八、派生分析（独立目标类型，非内核对象本身）：概率外衣=胜诉率（显式目标总体/结果变量/观测机制，不可识别即 UNKNOWN）；行为外衣=DecisionProgram；对比外衣=偏离度三算子与倾向分层。

九、边界：六类不可表达边界定理未证=UNKNOWN，仅作边界管理不作封闭主张；缺证据永不冒充结论。

## 冻结程序（Object Definition Change Control）

后续改动须同时满足三步，否则一律视为实现层变更、不得解冻：
1. 提交能击穿 v3 的**最小反例**，指明哪条定义无法表达/矛盾/错误推导；
2. 证明该问题**不能**通过下层规则、类型扩展、算法、证明或工程实现解决；
3. 修改后对受影响条款重新执行**局部对辩审计**，不得因新增功能重开对象体系。

## 工程实现警告（R5 残余检查，违反=实现不符规格，非改定义）

- K_{e,t} 不得偷换成单一"当前最可能状态"——它是候选状态集合；
- Disposition 不得重新编码成 Judgment 的枚举成员；
- 裁判事件不得统一实现成"判什么 R 就变什么"。
