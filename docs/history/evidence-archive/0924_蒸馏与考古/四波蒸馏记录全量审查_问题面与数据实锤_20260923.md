## 3. 对统一模型与施工的影响

- **R2/R5/R8/R9/R10 → 1.5 数值层**：ExactExpr 的法定表达式构造清单从这些簇直接生成（分段利率/倍数/阶梯/封顶四类算子）；TaxCalcBench 可作外部对标。
- **R1/R4/R15/R30 → 1.4 时序+程序层**：执行/破产/溯由是状态机+偏序的实际载体；公理博弈论 priority bankruptcy 是 R3/R4 的数学工具候选。
- **R12/R17/R36 → 语境路由函数**：案由→请求权→管辖、连接点→法域，是 ContextKey 选择函数的现成规则源。

- **R33/R34 → 工作台侧资产**（不进推理内核，进 manuals/harness 提示）。
- **施工顺序修正**：R2 利息族与 R11 期间族应排最前（规则密度高、纯确定性、直接落 1.5/1.4 层）；R18 土地征收簇体量最大但法源地方化强，排后并逐省核验。

## 4. 结论

四波记录是比七册书**更宽的问题面**（37 新簇 vs 书的 46 问，交集仅方法论部分）：书的重心在"法律能不能被计算"，记录的重心在"这一条怎么算"。统一模型若只吸收书证层，会漏掉中国实务全域的确定性计算面；若只吸收记录层，会失去形式化边界意识。两层都要——书证层定语义骨架（七层模型），记录层供规则存量（施工素材库）与外部基线（TaxCalcBench 类）。
