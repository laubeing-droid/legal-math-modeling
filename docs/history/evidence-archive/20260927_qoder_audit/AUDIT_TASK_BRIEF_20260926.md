2. **防编造证据规则**（最高纪律）：每一条结论必须附证据＝`文件路径:行号` + 原文短引（引原句，不许转述）。禁止凭你的训练记忆描述这个仓库的内容；文件不存在、行号对不上、内容查不到——一律写 **UNKNOWN**，不许猜。宁可十次 UNKNOWN，不许一次编造。

4. **结论可推翻**：每条 FAIL / PARTIAL 必须附"反证路径"——用户复核时打开哪个文件哪一行就能验证你的判定。
5. **术语配人话**：首次出现的行话跟一句大白话。已定义如下，报告里沿用：
   - **见证级**＝只对具体例子证明（如"这三个元素排完确实降序"），不是对任意输入；
   - **一般式**＝对任意输入成立的定理（数学上真有内容的那种）；
   - **降级**＝本想要一般式、只交付了见证级，必须在台账里诚实登记；
   - **空真（vacuous）**＝前提永远不成立，定理形式上为真但没有任何内容；
   - **涵摄**＝把具体事实归入法律要件的操作（大前提套小前提）；
   - **回执**＝一条输出所附的凭条：依据什么、能主张到哪一级（结论级/参考级/不可主张）；
   - **主体定理 vs 工程定理**：前者是法律数学内容（要件、证明责任、金额、概率、量刑），后者是工程防护（防幻觉开关、幂等日志、版本拼接、人机闸门）。
