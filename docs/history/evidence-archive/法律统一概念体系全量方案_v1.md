## 零、骨架一页纸（先讲清楚系统是什么）

**七层两横切。** 从抽象到具体排七层，过程在承载上展开：

| 层 | 名字 | 一句话（人话） |
|---|---|---|
| L0 | **概念层** | 法律概念的户籍簿：什么叫做"请求权""时效""构成要件"，每个概念一条定义、一个编号 |
| L1 | **法源层**（实体承载） | 法条、判例、司法解释的真身：哪个版本、现行吗、位阶多高、什么时候生效——概念踩在承载上才有内容 |
| L2 | **问题与要件层** | 先判断这是什么法律问题（定性/争点），再拆构成要件 |
| L3 | **证明与责任层** | 证据进不进得来、证明到什么程度、举证责任在谁 |
| L4 | **论证与裁量层** | 双方怎么攻防、条文怎么解释、量刑怎么量、谈判怎么谈 |
| (L5) | **计算与保证层** | 机器内核：规则推演、金额计算、证书签发。加括号=机器自动过，不是人工站 |
| L6 | **交付与工作台层** | 文书、审计视图、人机复核包——交到用户手里的东西 |

**两横切**（贯穿七层的两条规矩，不在序列里）：
- **经验校准**：真实数据（1.5 亿文书库、检索、胜诉率、偏离度、倾向）从这条进系统喂参数；
- **回执**：每层每句话输出时必须带"可主张等级"——**结论级**（有证书）/ **参考级**（仅供参考）/ **不可主张**（没依据）。没有回执的层要登记"我没回执"，它的输出自动降为不可主张。

**办案流程**（按你的实际工作方法修正：**判断在前，找法在后**）：
> ①定性（这是什么法律问题→争点）⇄ ②找法（现行法源，可来回循环）→ ③定要件 → ④证据证明 → ⑤论证裁量 → (⑥机器计算) → ⑦交付

**三把尺子，三个名字，永不混用**（回应"以后叫 AI 编程会不会乱"）：
- 说 **"层"** = 本方案的法律语义七层（L0–L6）；
- 说 **"轨"** = jusbench 的改动节奏七轨（算法轨/规则轨/知识轨/数据轨/维护轨/账本轨/产品轨）；
- 说 **"序"** = 证明目标的依赖位序（序 1–序 23）。
指令里写哪个词就是哪把尺子，词不同、物不同，AI 编程不会串。

## 四、我们的定义词（本书用词，一锤定音）

| 词 | 定义 |
|---|---|
| 层 | 法律语义七层 L0–L6 的"层"。只此一个含义 |
| 轨 | 改动节奏七轨（算法/规则/知识/数据/维护/账本/产品）。jusbench 文档用 |
| 序 | 证明目标的依赖位序（序1–序23）。排施工顺序用 |
| 概念层 | L0。法律概念的户籍簿，只管"是什么、叫什么、怎么定义" |
| 法源层 | L1。法条判例的实体承载，管"哪一版、现行吗、位阶、时效" |
| 定性 | 办案第一步：判断这是什么法律问题、争点是什么。在找法之前 |
| 现行性 | 一条法源此刻有效且未被修订替代。L1 的闸门 |
| 要件 | 结论成立必须满足的条件集。L2 |
| 争点 | 双方真正有分歧的要件或问题。L2 |
| 证明标准 | 排除合理怀疑/高度盖然性/优势证据，三级阈值。L3 |
| 举证责任 | 事实真伪不明时谁承担败诉风险。L3 |
| 涵摄 | 把事实归入要件的算子。L2→L3 |
| 攻击/击败 | 论证层一方削弱另一方的可废止关系。L4 |
| 扩张/限缩 | 解释拉大或缩小概念边界。L4 |
| 回执 | 一条输出的依据凭条：谁签发、依据什么、能主张到哪级 |
| 结论级 | 有证书（数学证明/检查器通过）的输出。机器可当结论 |
| 参考级 | 有依据但无证书（候选、统计、外部评审）。只能参考 |
| 不可主张 | 无回执层或依据缺失的输出。系统必须拒绝当结论使用 |
| 候选 | LLM 或检索产出的提案，永远不是结论，须过准入 |
| 待登记债 | 网盘账本里的编号（131、T 系、R 簇、辩:轮次），映射表交付前不得冒充仓库户口 |
| LME: | 语料自身 ID 前缀（Legal Math Evidence），不绑存储路径 |
| 映射表 | 【已废】旧方案的"把网盘账对到仓库"的做法。由本全量方案替代 |
| Horn | "如果条件则结论"的规则形。内核推演的基本件 |
| AAF/Dung | 论证图与攻击语义：谁攻击谁、谁被接受。L4 内核 |
| 证书 | 数学层面的保证件：定理、检查器通过记录。证书证明绑定，不证明真理 |
| 胜诉率三步 | 检索定母体→母体实算→与本案对比。横切A |
| 偏离度 | 本案结论与参照集合（自己过往/同侪/上级）的结构差。横切A×L4 |
| 倾向 | 某法院/法官/地区在时段内的裁判模式。横切A×L4 |
| 量刑双线 | 规范线（比例表/细则）+经验线（判例统计），T112。L4×(L5) |
| BATNA | 谈判破裂时的最佳替代方案估值。L4 |
| ZOPA | 双方可成交区间。存在性可判定。L4 |
| 让步阶梯 | 让步幅度单调递减的结构（如 20-10-5-2）。L4 |
| NN 带证书逼近器 | 神经网络拟合经验规律，必须附"误差界"证书才可进系统。(L5)×横切A |
| 提示词资产 | 话术、逐字稿、语气档。属 L6 交付资产，不是法律概念；机器只验"不冒充法律事实" |
| 花钱通道 | 动类型户口本的动作：类型数变化→相关定理全部重验→CI 重跑，需单独授权 |
