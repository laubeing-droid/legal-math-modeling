### 1.2 联合语义与请求的能力集合

\[
\Phi_{v,c}(I,w)=\Phi_N(I,w_N)\land\Phi_P(I,w_P)
\land\Phi_X(I,w_X)\land\Phi_G(I,w_G)\land\Phi_{join}(w).
\]

\[
\mathcal S_{v,c}(I)=\{w\mid\Phi_{v,c}(I,w)\}.
\]

\(I\)包含证据、准入事实、假设、规则、概率模型、经验数据、目标和效用。每个\(\Phi\)在实现之前独立陈述。规则语义不能是“程序输出的集合”；合法行动不能是“优化器选到的行动”；模型定义不能是“模型当前报出的数字”。

join约束的是同一输入/版本/情景与真实中间值，并不是强迫“预测法院会做的事”都属于“法院依法应做的事”。经验裁判事件与规范允许结果使用不同目标类型。请求只要求部分能力时，未请求模块不成为无根据的失败前提；请求策略但合法互利交集为空，返回有证据的无可选行动状态，不能抹掉已经完成的规范结果。

### 1.3 结果表示，而不是只认有限列表（REV01）

定义受支持的表示语言\(Rep\)与解释\(\gamma:Rep\to\mathcal P(W)\)。示例：有限枚举、实数闭区间、有限区间并、有理系数实多面体、已注册的符号关系。任意Python回调不属于可接受的表示语言。

\[
CheckExact(v,c,I,r,\pi)=accept\Rightarrow\gamma(r)=\mathcal S_{v,c}(I).
\tag{G-Exact}
\]

\[
CheckPartial(v,c,I,r,\pi)=accept\Rightarrow\gamma(r)\subseteq\mathcal S_{v,c}(I).
\tag{G-Partial}
\]

\[
CheckOuter(v,c,I,r,\pi)=accept\Rightarrow\mathcal S_{v,c}(I)\subseteq\gamma(r).
\tag{G-Outer}
\]

即\(\gamma(r_{inner})\subseteq\mathcal S\subseteq\gamma(r_{outer})\)。数值查询\(q\)的界满足\(\forall w\in\mathcal S,L\le q(w)\le U\)。原来的完整解等式与部分解子集是有限表示的特例，不被削弱。

**参考代码已给出：**`check_interval_exact`对有限条上下界取max/min，精确表示整个实区间，而不是端点。多面体采用\(Ax\le b\)约定：目标每行由源行非负组合推出，反向也给组合证书才认可精确等价。此种证书不完备：不能提供证书意味着检查未通过，不意味着集合必然不相等。没有隐含\(x\ge0\)，需要时写进约束。

**证明步骤：**
1. 区间：\(\bigwedge_i l_i\le x\land\bigwedge_j x\le u_j\iff\max_i l_i\le x\le\min_j u_j\)。端点反序证明空集；非退化区间的中点反驳端点枚举Exact。
2. 多面体：给\(\lambda\ge0,\lambda^TA=c^T,\lambda^Tb\le d\)，由\(Ax\le b\)推出\(c^Tx\le d\)。逐行得到包含，双向得到等价。
3. 有限并：证明\(\gamma(union(r,s))=\gamma(r)\cup\gamma(s)\)，并对并中每个分支的来源/范围验证。这个通用构造未给专用运行检查器之前不能开放任意输入。
4. 代表一个最优点的证书只能证明成员及最优性，不能因此声明列出了全部最优点。要返回全部最优解，可验证原多面体加最优目标等式所定义的最优面；不靠枚举连续点。

## 2. Python怎么写算法、Lean怎么证明算法

Python承担：封闭输入校验、实际算法、证书生成、独立检查、回放和测试。`assert`与随机测试不能成为无限量词数学证明。Lean承担：独立语义、算法反射、循环不变量、范围覆盖、组合与外包络保持。论文提供研究依据，不自动提供本项目证明。

### 2.1 有限扫描与独立检查（REV03）

候选域\(C\)必须有独立覆盖证据，判定器\(b\)必须证明\(b(x)=true\iff P(x)\)。扫描保持：

\[
C=A\mathbin{\dot\cup}R\mathbin{\dot\cup}U,
\qquad A\subseteq\{x:P(x)\},\quad R\cap\{x:P(x)\}=\varnothing.
\]

空前缀成立；遇到可证真者移入A，可证假者移入R，未知/超时留在U；每次转换保持三不变量。只有\(U=\varnothing\)且\(P(x)\Rightarrow x\in C\)才得到完整等式。`complete=true`不是证据本身。

`v21/checker.py`把候选构造与成员检查锁在已登记类型内，证书不带提交者可选predicate。Dung求解侧调用保留的参考算法；检查侧独立实现冲突自由、防御、特征函数、极大性。共享Fraction、结构类型等基础原语并不被禁止；必须明确哪些共享原语可信，哪些具体反射还待证明。

示例调用（仓库根执行，包内路径导入后即可运行）：

```python
from fractions import Fraction as Q
from v21.context import synthetic_context
from v21.checker import AffineIntegerProblem, solve, check_partition
c = synthetic_context()
p = AffineIntegerProblem(0, 8, Q(2), Q(1), Q(8))
certificate = solve(c, p, budget=5)
assert check_partition(c, p, certificate)
assert not certificate.complete
```

这里只测试了这一输入。对应普遍定理要把`AffineIntegerProblem`及其检查算法编码成Lean、证明算术反射和候选域覆盖，再实例化原`scan_partial/scan_complete`。把整个结论设为前提后展开，不叫完成这一实例化。

## 3. Horn、论证生成和扩展：把有限性说清楚

### 3.1 Horn与撤回

\[
T_R(S)=S\cup F\cup\{h:(B\to h)\in R,\ B\subseteq S\}.
\]

固定有限原子域上单调且扩张，从空集开始至多\(|A|\)次严格增长。证明迭代包含域、单调增长、稳定后不变、最小性。复用已有Horn不动点证明，不另造一套。

增量目标：
\[
Incremental(F,R,\Delta)=Full(F\cup\Delta_F,R\cup\Delta_R).
\]

证明工作表不变量：已处理规则不会遗漏新触发前提、每个加入原子有原始或规则见证、队列空时闭包封闭；由最小性双包含。删除、撤回、规则改写、解释变化、域增长按实际适用条件全量回退或另证减量算法。反例：撤销a后不得保留仅由a→b获得的b。

### 3.2 论证域与新旧表示（REV06）

有限原子不等于只有有限种论证。用出现位置树表示：
\[
Arg_0=\text{已准入／显式假设叶},\quad
Arg_{d+1}=Arg_d\cup\{\langle r,a_1,\ldots,a_k\rangle:\forall i,a_i\in Arg_d\land concl(a_i)=prem_i(r)\}.
\]

给定有限叶、有限规则、有限有界元数与固定d，证明每层有限。双向证明生成器输出恰是该深度语义中的合法树：健全性按生成步骤归纳，完备性按目标树高度归纳。零前提规则需要明确被准入的规范/公理来源，不能把任意结论当无来源叶。

树身份包含规则ID、子树、叶来源、假设、语境；不能只按结论哈希合并。`v21/argument_mapping.py`用节点出现位置保留有限树，再对要投影到旧按原子图的对象检查合并后无环；不能处理的返回不支持，不伪造等价。

当前代码实现的是出现图与保守投影检查，不是完整ULM08精化。完成精化还需证明根、所有支持边、假设依赖、子论证攻击靶点与请求索引都被保持。`a叶→b→a根`是有限树，但按a合并会成环，应拒绝该简单投影，或启用经过独立证明的带出现索引新表示。

### 3.3 截断与扩展

\[
Defeat_{impl}(a,b)\iff DefeatSpec_{v,c}(a,b)
\]

先解决攻击的靶点、权限、优先政策与例外，再抽象到Dung。grounded取特征函数最小不动点；complete是可容许不动点；preferred是完整候选域的极大可容许集；stable要求集合内攻击所有集合外。

**不能证明的一般断言不硬证：**深度d求解出的扩展未必是深度d+1的扩展，更不一定是未截断系统的部分有效解。证书必须明确`height≤d`。从浅域迁移到完整域，需要攻击边界封闭、遗漏论证对查询的不可影响性等额外条件，并对具体profile证明；没有这些条件不升级。

原有三环无stable与空图具有一个空扩展的防护保留。不完整扩展族中：一个接受见证可支持存在命题；一个反例可否定全称；没有找到不能证不存在；所有已找到都接受也不能证共同接受。preferred候选的极大性不能仅在已搜索前缀内验证。

### 6.2 后验与变量消去

\[
w_m(x,e)=P_m(x)L_m(e\mid x),\quad Z_m(e)=\sum_xw_m(x,e)>0,
\quad P_m(x\mid e)=w_m(x,e)/Z_m(e).

Z=0是该模型不能解释这组观察，返回不相容，而不是事件概率零。联合归一化按逆拓扑逐个求和消去子变量；后验范围由权重非负及总质量得到。变量消去以有限求和交换和分配律证明每次因子消元保持边界变量上的边缘函数，最后证明归一化一致。不是用“枚举和消元碰巧测试一致”代替全称定理。

赔率更新必须保留证据历史条件：
\[
\frac{P(H\mid E_{1:n})}{P(\neg H\mid E_{1:n})}
=\frac{P(H)}{P(\neg H)}\prod_i

\]

只有已声明、可辩护的条件独立性才可去掉历史。副本、引用和模型复述不新增独立证据。参考`BoundObservation`按实际源族去重，并在同源被拆为不同独立观察节点时保守拒绝，要求显式联合/潜变量模型；这只是依赖治理，不是自动发现所有真实相关性。

### 6.3 数据学习与备选模型

\[

### 6.4 误设与搜索中断

更新后污染模型\(P^*=(1-\epsilon)P+\epsilon Q\)，且\(P(H)\in[l,u]\)、Q任意：

\]

证明是事件概率线性分解和Q范围。更新前的污染预算不能无条件继承到条件化后的后验；后验污染权重取决于两部分证据似然。未识别的结构误设须通过额外模型、污染假设或明确外部风险说明处理，不能仅把“other”写成一个节点名。

已处理事件质量a、非事件质量b，剩余**未归一化质量的独立上界**r给出：
\[
P(H\mid e)\in\left[\frac a{a+b+r},\frac{a+r}{a+b+r}\right].
\]

以剩余事件/非事件质量非负、和≤r证明最坏端点；a+b=0且r>0给[0,1]；全部为0不可条件化。若r没有可验证上界，不能用猜测质量形成保证区间。

### 6.5 概率到法律结果的连接

历史事实F、机构认定A、裁判结果Y分开：
\[
P(Y\mid E)=\sum_{f,a}P(Y\mid a,f,E)P(a\mid f,E)P(f\mid E).
\]

对已定义的情景权重\(p_x\)与法律允许集合S(x)：
\[
\underline P(H)=\sum_xp_x\min_{y\in S(x)}1_H(y),\quad
\overline P(H)=\sum_xp_x\max_{y\in S(x)}1_H(y).
\]

如果情景选择彼此独立且每个端点可同时达到，它们是精确界；共享解释/参数/策略时一般只作外包络。空集合、不完整分支、未分配概率质量不能设为0再偷偷归一化。只找到部分法律解时不能直接拿部分集最小/最大值当全体概率界。

概率不自动构造verified_fact。先解决该争点的准入/假设/程序角色，再进入条件规则计算；民刑证明标准不是0.75/0.95法定阈值。

## 8. 来源明确的精确计算与裁量

### 8.1 类型与算术

\(Quantity=(q\in\mathbb Q,dimension,basis,source,rounding,scope)\)。币种、天/月、年利率基础、债务项目不可混加。不同单位转换要有明确政策；月不是永远30天。全程Fraction或精确整数，最后按指定规则舍入，并证明舍入误差界或保留精确值和展示值。

### 8.2 可行域优先于最优化

\[
\mathcal F_{v,c}(f)=\{y:C_{v,c}(f,y)\},\quad
Y^*=\arg\min_{y\in\mathcal F}L_\theta(y,f).
\]

硬法律约束不能被效用权重抵消。\(\mathcal F\)可空、离散、不连通、多解；支持集合与外包区间分开。当只找到部分解A：\(\min\mathcal F\le\min A\)、\(\max A\le\max\mathcal F\)，不能反向宣传为全局界。

区间运算用有序域单调性/四端点乘积证明包含；除数含0则拒绝有限除法区间或给受支持的分裂/无界表示。空域、未找到、最优值未达到、最优点已找到、全部最优集已表示五者分开。

### 8.3 LP、凸性、整数规划

\[
\min c^Tx\ s.t.\ Ax\ge b,x\ge0;
\qquad\max b^T\lambda\ s.t.\ A^T\lambda\le c,\lambda\ge0.
\]

弱对偶链\(b^T\lambda\le x^TA^T\lambda\le c^Tx\)。原/对偶可行且目标相等推出全局最优，不需要把强对偶当假设塞进每个证书。若要证明证书一定存在，再单独处理相应可行/有界等条件。

二次凸性可给精确\(H=LDL^T\)、D对角非负证书，证明\(z^THz=(L^Tz)^TD(L^Tz)\ge0\)。KKT在可微凸目标与凸不等式/仿射等式下的充分性用凸函数一阶界；必要性与约束资格另证，不能混用。[M-CONVEX]

MILP先采用有限整数域穷举参考，再引入分支定界。每次分枝须覆盖父域；剪枝需要独立有效界；最优性需要所有剩余分支界不优于incumbent；预算用尽只报告可行点和界差。连续松弛中的小数方案不能当整数可行方案。完整argmin表示还要保留并列最优分支，不能因已经找到同值点就错误删除全部同值解。

## 9. Banach：证明一个实际算子符合条件（REV08）

本轮指定：
\[
f(x)=\tfrac12ax^2+bx,\quad a>0,\quad x\in[\ell,u]\subseteq\mathbb R,\quad\ell\le u.
\]
\[
T(x)=\Pi_{[\ell,u]}((1-\eta a)x-\eta b),\quad 0<\eta a<2.
\]

依次证明：闭区间非空且完备；投影保持域；投影非扩张；\(k=|1-\eta a|<1\)；\(|T(x)-T(y)|\le k|x-y|\)；最后调用固定mathlib版本的Banach定理得到唯一不动点与迭代收敛。

最优点\(x^*=\Pi_{[\ell,u]}(-b/a)\)。用三个位置分支或变分不等式，证明\((ax^*+b)(x-x^*)\ge0\)；再展开
\(f(x)-f(x^*)=\tfrac a2(x-x^*)^2+(ax^*+b)(x-x^*)\ge0\)。这一步真正连接固定点与目标，不只证明“某处存在点”。

后验误差：\(|x-x^*|\le |x-T(x)|/(1-k)\)。如果实际迭代舍入有界\(|\widetilde T(x)-T(x)|\le\delta\)，则按递推
\(e_{n+1}\le ke_n+\delta\)，得到\(e_n\le k^ne_0+\delta(1-k^n)/(1-k)\)。不能无误差项把舍入程序当实数精确T。

有理数计算嵌入实数空间，不称Q完备。具有离散资格、非凸合法集合、非二次目标的法律问题不能用此证书。业务适用还要验证目标/单位/域确实与所讨论子问题一致；本轮不声称一般司法评价都压缩。

## 11. 真正避免定理岛：组合、实例化与总声明
