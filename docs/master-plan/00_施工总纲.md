## 一、对象（已冻结，禁改）

**法律语义内核对象 v3**（全文见同目录 `基线/对象定义v3_冻结版_20260925.md`）：
- B_t = (R_t, K_{e,t})：规范本体状态 + 证据可支持状态集合；
- Truth(q, R_t) 与 Judgment(q | K_{e,t}, P, V) 分层，Judgment=不成立 ⇏ Truth=false；
- Eval(q) = (Judgment(q), Disposition(q))，Disposition 是结果字段非第四值；
- R_{t+1} = T(R_t, EffectType(JudgmentEvent))，确认性裁判不创造关系；
- ApplicableNorm = A(J, V, q, H, t)；
- Power / Obligation / Occurred Event 互不推出；
- 未决条件窄化（穷尽举证责任/推定/妨碍/终结规则才未决）；
- 概率/行为/对比三外衣=派生分析（独立目标类型）。
**程序锁**：改对象定义须过三关（最小反例→证明下层不可解→局部对辩审计）。
