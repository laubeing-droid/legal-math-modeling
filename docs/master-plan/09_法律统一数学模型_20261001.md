## 一、统一口径（Owner 2026-09-29 裁决，本件不得改写）

统一 = **理论统一** = 从一个统一数学概念逐步推导：

```
L0 法律概念 → L1 法律本体 → L2 规范运算 → L3 推理 → L4 概率
           → L5 博弈行为 → L6 制裁后果 → L7 运行闭环
横切：时间 XT ｜ 不确定性 XU
```

工程层（接口、CI、台账、证书）是实现与取证手段，**永远不许冒充统一本身**。
"某模块已接线、某流水线已绿"在本件里只能作为证据出现，不能作为结论出现。

## 二、𝔐 的契约（声明片段版）

𝔐 不是一个"把所有东西塞进去"的大结构，而是**一个法律对象域 + 一族分层观测 + 一条链式推导关系**，
且必须显式携带它管不到的部分。契约形状：

1. **一个法律对象域** `α`：L0/L1 的同一载体，各层不再各自发明对象。
2. **一族声明观测** `Φ : ι → (α → γ)`：每层对同一 `α` 只声明自己那一族观测；`ι` 是*声明*出来的，
   未声明的观测不参与本层的任何定理（这是"未覆盖片段"的机制，不是免责声明的修辞）。
3. **各层的表示与保义**：每层给 `enc / dec` 与观测族搬运，且**保义要求双向**：
   往返（`dec ∘ enc = id`）+ 覆盖（`enc` 满）。单侧逆只给嵌入，不给同构。
4. **链式推导关系**：`Derive_i : L_i 的对象 → L_{i+1} 的对象`，每一跳是一条具名定理，
   写明前提片段与结论；层与层之间不许用"接口兼容"代替"语义保持"。
5. **非退化**：𝔐 的联合载体不得被观测族压扁——必须能交出两个不同对象与一个把它们分开的声明观测。
   没有这一条，"存在一个统一模型"永远是空话。
6. **有限过程组合**（L7）与**时间/不确定性保持**（XT/XU）各是一条独立定理，不并进 1–5 里蒙混。

总定理签名（T2 已写并编译；CI `36770475007` @ `c03663cb` 构建绿，8527 目标计划）：

```

    {V Rel : Type} [DecidableEq Rel] (M : UnifiedModel V Rel) :
    UnifiedNonDegenerate ∧ UnifiedInterpretationPreserved V Rel M ∧
      UnifiedChainCorrespondence V Rel M ∧ UnifiedFiniteProcessComposition V Rel M ∧
      UnifiedTimeAndUncertaintyPreserved V Rel M := ...
```

它在 `Seams/Unified.lean:236`。文件自带的 doc-comment 把它的强度说死：合取支 (1) 由
`unified_model_is_not_vacuous` 交出，(2)–(5) 的证明项**只是** 8 个缝件模块共 21 条已设定理
作用于片段字段，**本件内没有任何新的数学论证**——"统一"在这里是组合事实，不是新证明。

## 四、已落地内容的实际陈述（P-034）

请求权基础链是**唯一一件已经落到 Lean 的链式层**，它示范了本模型要求的形状：

- **法律语义**：成立 / 障碍 / 消灭 / 可行使四段；差别是结构性的——障碍除去后请求权复活，消灭是终局。
- **数学对象**：`Stage × Polarity × holds × normId` 成 `Node`（引证是**字段**，不是事后贴的标签），
  `Status` 五值，`fires` 是裁决表，`Step`/`Walk` 是转移与链推进，`CitedAt`/`CarriesCreationBasis` 把
  "这条链带不带成立段引证"做成**位置化**事实。
- **定理**：从"尚未成立"出发、终局不是"尚未成立"的任何链，必携带一条成立段命中规范
  （`walk_verdict_needs_basis`，链上归纳）。四段各自实例化。
- **反向是条件定理**：候选表内无一成立 ⇒ 本案无基础，**只在语料被显式声明为封闭时**成立
  （`exhaustive_refutation` 的前提 `hclosed` 写在签名里）；`closure_premise_is_not_free` 交出缺该前提时的失败见证。
- **两条边界**：同一无序节点集在不同检验序下结论不同（`order_matters_same_node_set_different_verdict`）；
  可达性为真时按序结论可以只是"被阻却"（`reachable_but_not_established`）。
  ⇒ 一般图可达与 Horn 闭包正确都**替代不了**这一层。
- **不证什么**：本件不定义证据标准、不定义制度后果、不认定任何真实案件的请求权成立与否。
