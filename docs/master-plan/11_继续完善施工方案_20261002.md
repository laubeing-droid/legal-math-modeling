## 二 本轮唯一目标：把"统一"写成可机器判定的东西

Owner 口径：统一 = 理论统一。契约原文 `09:31-40` 已列六件（同一对象域 `α`／声明观测族 `Φ`／每层 `enc·dec` 双向保义／每跳具名 `Derive_i`／非退化／有限过程组合与横切各一条）。
本方案把它收成**一条可判定的定义**，此后"统一"只许按这一句使用：

> **𝔐 统一** ⇔ 存在一个 `UnifiedModel` 的**闭合项**（照 Mathlib 的形状交出可满足性见证：`Mathlib/ModelTheory/Satisfiability.lean:65 def IsSatisfiable : Prop`，
> 而**不是**散文声明有人住。注：pin 里的 `nonempty_iff` 在 `ModelTheory/Semantics.lean:1067`，它是同构两边的非空转移，**不是**居留定理；
> 文献线报的 Types.lean:159（上游 master 的位置，本仓 pin 无此路径可核），本会话按 pin 重取为 `Satisfiability.lean:65`），
> 且契约每一对相邻层有一条**具名迁移函数**与一条**解释保持定理**，每个二元复合有一条 `compose` 型定理**能在该闭合项上真的归约**，
> 且非退化见证是**关于该闭合项**的（不是三个硬编码全局对象的合取），
> 且至少存在一条**端到端链**：已逐字核验的条文 → 经 ≥2 跳迁移 → 落回一个可主张的法律结论。

配套四条诚实判据（现状 **0/4**）：
1. 桥必须是可计算的具名函数，不得只出现在假设位；
2. 保持引理取"本层自身可证的单向健全 + 反向给反例"这一档（仓内既有风格：`SourceNorms.lean:192/:216`）；
3. 复合律要有具名定理，并能在闭合项上归约——**用"八层同名"或"import 了"顶替这一条就是偷换概念**；
4. 没桥的相邻对必须登记为未覆盖片段并降档。
