    `checkQE φ cert ψ = true → ∀ρ, denote φ ρ ↔ denote ψ ρ`。

    ⑤ 用合成破坏确认删格、漏根、错符号、错量词、错输入绑定均被拒绝。至少覆盖有理／无理根、重根、降次、无解、自由参数和交替量词，不能只验两个封闭句。

    对某个固定输入逐例手写代数证明，**可以算那个实例已验证**；不能算通用 CAD/QE 检查器已完成。QEPCAD 不导出所需数据时，恢复原合同的参考生成／补齐路线：[附录J:22](D:/Codex/1.法律工作区/legal-math-modeling工作区/legal-math-modeling/docs/spec/20261007-统一法律数学模型_附录J_Python施工明细.md:22)。外部生产失败如实开放，但不能取消参考完整生成器的全称义务。
