# CN 制度、法律读数与学习反馈的共同数学结构

本稿承接 v4 的共同法律世界及后续四面纠正，补回执第四章第6、8项及审阅稿F7/F13/F14。法律判断的含义、规范版本、支持的解释、权限及效果仍取既有模型；以下证明连接这些已有对象，没有另做法理学定义。构造和证明的源码、验证与条件表在《CN工程附录》，不放进本层。

## 1. 共同对象不是几个互不相通的结果表

令 S 为已有的完整法律情形：实际发生 F、证据 E、规范及授权 N、法律关系 L、拘束、裁断、程序、分账和私人参数同时属于 S。给定初态 s₀ 和一组完整带类型的命令 cₐ，令

\[
R(h)=\operatorname{fold}(\operatorname{actualStep},s_0,h),\qquad
\Theta(h)=R(h).A.\theta,\qquad e(h)=(h,\Theta(h)).
\]

这里的每个 cₐ 都保留原命令的结果类型和全部输入，包括具名规则、解释、材料、权限和原生计算载荷。R 读取实际命令解释器的完整后态。法律关系不由余额逆推；法源、主体及范围也没有变成几个数值。

对每一个有限实际命令串，可以取该串本身为目录并无损重放。因此“有限目录”是当前过程的局部表示，不是法律系统、状态或法律解释的全局有限性假设。对每一个这样的目录，可以给任意可测的命令选择核 π(h,θ)；π 无须常值，也不要求忽略已学习的参数。

令一次命令完成后的共同更新为

\[
\Phi((h,\theta),a,*)=(h\mathbin{+\!+}[a],\Theta(h\mathbin{+\!+}[a])).
\]

等式的第二坐标并非另造学习器：先实际执行 cₐ，再读取该后态的 A.θ。拒绝、未知、争议和待人工处理也保留为实际结果，实际失败不会伪装成成功。

**交换定理。** 对每个 h,a，实际命令后态的表示等于 Φ(e(h),a,*)。证明：有序重放的最后一步就是原解释器执行 cₐ；两边第一坐标都是追加后的完整命令串，第二坐标都是这一次原解释器后态的私人参数。

**核与下一轮定理。** 在 π 为所声明的 Markov 核时，

\[
K(e(h),B)=\int 1_B(e(h\mathbin{+\!+}[a]))\,\pi(e(h),da),
\]
\[
\pi_{\rm next}(e(h),D)=\int
\pi(h\mathbin{+\!+}[a],\operatorname{actualStep}(R(h),c_a).A.\theta)(D)
\,\pi(e(h),da).
\]

证明是把同一次选择经 Φ 推前，再按同一核复合。第二式明确读取更新后的历史与实际私人参数。第一步的私人参数不是冻结到后续各轮的常数。

这一 π 是过程的生成模型。若它被解释为某个主体的实际策略，仍按原边界要求它只因子化于该主体真实可用的资料与自己的参数；不能把描述者的完整历史自动当成主体知道的一切。

## 2. 法律实体、运行、数量与私人学习来自同一次后态

查询绑定 R(h) 中实际选中的规范、批准方法及同一个相容世界：调用的自然世界取该世界的自然投影，查询事项和原有主体/时间/范围索引相符。批准方法产生的确定结论经原有细化定理进入同一相容世界；自然事实不因此被强制改写成材料的说法。在这个一致查询下，分别读取六个判断：世界中的真实、材料支持、依批准方法成立的论证、实际裁断认定、裁断效力、指定种类及人/事/时间范围内的拘束。它们保留不同的值型及未知出口。没有存储的拘束索引时保留未知，不从空列表推得终局无拘束。

四种效果也分别读取：效力、终局拘束、与给定法律世界评价的相符性、实际履行。法律世界的评价未定时，相符性仍未定；有有效文书也不会生成一笔实际付款。

把这些法律读数、完整数量账本以及私人参数合成一个读数 G。上节交换定理推出

\[
G_\#K(e(h))=(a\mapsto G(\operatorname{actualStep}(R(h),c_a)))_\#\pi(e(h)).
\]

这是一条联合律的推前。法律效果、数量和学习结果保持相关，没有分别抽取三个边际再拼成一个从未发生过的共同结果。

## 3. 十二制度沿同一更新进入模型

下列实例各自保留原来的制度判断与失败出口，再将实际结果运送到上述共同后态。证明使用已有的具体制度证明，而非重新给制度贴一个算子名字。

| 制度 | 由实际调用保留的数学含义 |
|---|---|
| 民事法律行为生命周期 | 实际撤销移除被跟踪效果而保留实际事实；超出撤销时间的失败保留原效果；非司法形成不虚造裁断和拘束 |
| 代理 | 派生授权实际进入授权登记并保留本人的能力；超出原授权范围的请求不能改写登记 |
| 管辖 | 普通管辖与专属分支的结果不同，不把没有普通管辖当作未知或任意获准 |
| 证据 | 待准入、已准入和已排除产生不同论证结果；排除保留原材料及实际事实 |
| 善意取得 | 善意、已证明恶意和特殊遗失物路线分别产生不同结果，不从无证据的善意推定成功 |
| 共同犯罪 | 人、事件和罪名/共同范围绑定；未见第二事件不能把第一事件的参加事实复制过去 |
| 破产 | 受理、债务人、执行中止和利息截点同源；其他债务人及原已发生利息保留 |
| 国家赔偿 | 具名赔偿轨道单独改变；缺少终止等实际前提时仍未知，不把刑事、民事和行政责任混成一值 |
| 权利/规范冲突 | 保留争议及有权审查出口，不自动消除冲突或改写法律关系 |
| 表达式解释 | 当前实际存储解释被下一查询读取；规范版本及其他对象解释保持 |
| 既判力 | 读取真实存储的决定及拘束，区分人、事项和期限；有裁断不等于所有人/时点均被拘束 |
| DeepInfer 消费 | 实际原生结果成为候选，不直接产生裁断或拘束 |

给定相应制度参数，实际命令后态就是 R(h+[a])。所以表中的效果与失败出口同时进入 G、K 及下一轮输入。制度判断沿用原来来源/适用/权限条件；概率选择不能补造这些条件。

制度后态与私人学习的连接另给实质证明：从每个真实制度后态继续发生/记录/准入本次同一结果，登记并实际运行原生拟合、留存其报告，再用原学习命令载入该报告。准备条件只读规范版本及准入/学习的既有授权；规则列表、其余授权、关系和账户不被设回某个付款样例。代理新增授权仍在，撤销后的空关系仍空，破产中止、赔偿轨道、已存解释和拘束都保留；已有材料逐个保留，新材料和本次实际发生另行追加。

在这同一真实后态上，实际ERM、报告加载给出与 §7 相同的 after 投影，原响应概率律经该实际学习后态推前就是原数值核；后续法律策略按这个新后态取值。未满足另一制度自身许可条件时，学习不授予它新的许可。逾期撤销、越范围代理、特殊遗失物和缺赔偿前提等原失败结果仍保存在完整操作历史中，不因随后学习而被改成成功。

## 4. 原有八类数学能力实际进入学习循环

原生计算的完整带类型结果留在同一后态的报告中。拟合保留同一数据、候选和经验风险；概率保留同一先验及似然的后验；因果恢复保留原支持及识别条件；议价保留原获准菜单的最大值；现金保留同一实际付款及守恒；精确计算保留原表达式及值；行为响应保留其实际最优行动；RSI 保留实际评价/加载结果和原预算。

拟合还有后一条实质连接：实际ERM结果的表被留存，后续获准学习命令从该报告读取同一个表，写入同一情形的 A.θ，原来的 N/F/L 保持。它不是先证明一个拟合器、再另外假设某个私人参数恰好等于其输出。下一轮核按 §1 读取实际已加载的表。

RSI 的学习材料同样来自实际已评价且已加载的对象；未加载、未评价、冲突和拒绝没有这项表读数。多轮风险预算仍取原目标、同一风险总体及原验证条件。

## 5. 正向推导与当前 CN 证据语义相接

原题03.3要求的两个前提分别是：初始事实有支持；给定规则在同一规范和世界类上有效。二者都不由闭包算法替代。

以带符号的公式 (f,+)/(f,−) 作为查询解释。负文字明确表示 f 的反面成立；没有推出正文字不是负文字。若当前批准方法对某个初始文字给出确定判断，则已有细化定理把它运输到同一法律情形的每个受支持世界。对这些相同世界中的有效规则，旧有限闭包与相对健全/完备证明得到：每个被实际闭包导出的查询均成立；闭包也是相对于给定事实和规则的最小模型。

旧来源DAG的实际叶子、规则版本和逆序边检查也进入这个合成：被接纳的图给出无环来源、该实际叶子导出的闭包成员以及同一 CN 世界中的语义结论。不能用一份另外手写的事实表替换检查器实际收集的叶子。

本稿给出当前 CN 已准入材料的一个消费者：对同一受支持原子及其合取查询，实际批准方法、旧有限闭包和共同反馈后态的查询答案一致；相容世界非空由实际法律入口的已有证明产生。MustFacts 的严格包含反例也沿用旧真实求值器：两个分支分别含 a 或 b，两条规则分别推出 q；q 在每个分支闭包中成立，但仅先交事实再闭包会漏掉 q。

这保留了原题要求的相对正向片段、歧义、未定及显式否定，没有把任意 CN 含否定公式都偷换成无默认否定的正向 Horn 系统。

## 6. 全日志中四种身份的准确关系

完整操作日志的条目可以是实际发生、记录、准入、撤回、推导或学习。每个新操作追加一个fresh操作token，解码恢复完整原命令及其结果类型和载荷；在规范fresh编码的像上，重新编码与解码互为逆。每个实际 CN 有序历史不仅保留端点读数：完整命令串可重新构造原有端点依赖的历史本身，重建后再取命令仍是同一串；从实际历史取命令再重建，得到的是同一个“终态与原历史”的依赖对。固定初态时，命令串已能确定有端点历史；跨全部初态的全局编码另保存“初态、编码串”这对，因而每个初态的零步单位历史都保留，不能把不同根的空历史统统当成同一个空列表。

物理事件身份、测量身份、材料记录身份与操作token分开。一个只增加材料的操作会增加操作日志长度，却不增加物理事件 F；所以“只有新物理事件才增加完整操作日志长度”是错误命题。正确结论是：新的物理发生才增加物理事件清单；相同发生重放不增加它；不同记录、修订和学习仍是需要保留的操作。

v4 已允许 reports⊆Obs×Evt 为空、单值或多值。编码逐边运输整个关系，解码恢复每个相关和不相关的配对，不强迫每份材料有且仅有一个已识别事件。未解析资料完整保留，而不是强行制造一个物理事件。

在已有业务与 U00 记录中，实际 EventId、MeasurementId、RecordId、目标及机制版本同时保留。同一支付的复制记录使用同一既有事件身份；有效的新测量即使针对同一事件，也保留自己的测量身份和全部载荷。事件计数不会因此增加第二笔钱，测量资料也不会被一概删掉。完整业务动作串解码后继续使用原守恒及多轮预算证明。


## 7. 实际学习/履行 episode 与原数值循环的连接

数值实例中的 x 是上一轮行为结果的坐标，不是法律债额。实际金额仍由完整法律情形的同一原生账本保存。对任意有理状态 z=(x,θ)，在看到下一次结果之前给出两个候选表

\[
v_0=(0,\theta/4+1/8),\qquad
v_1=(1,\theta/4+1/2+1/8).
\]

本次已完成的结果为 Y∈{0,1}，样本只在第一个坐标使用标签 Y，损失为 (q−Y)²。旧实际ERM对两个候选的损失分别为 Y² 和 (1−Y)²；零损失者唯一，因而实际输出恰为 v_Y。第二个坐标由该被实际选中的候选承载，不能另外从另一支拼进来。

真实 episode 按前一轮完整后态顺接：选择一个实际行动、发生本次已完成结果、记录与准入同一资料、登记原生拟合输入、实际拟合并留存报告、从该报告实际加载表，再按先前行动与同一次结果执行原有履行命令。材料和现金事件身份从现有登记/历史的最大身份之后分配；旧记录、裁断、付款和参数更新历史保留。每轮没有重新回到初始样例。

给定原样例已经明确的规范、授权与批准方法，准入、拟合、加载和履行的成功来自现有守卫的实际求值。归纳不变量保留同一规范与来源、合法关系、批准方法，以及实际变化中的账户守恒/单位/当事人。它没有固定债额；原账户的分配及超额余额规则允许后续付款，不需凭空假设余额永远足够。

令 Ψ 读取实际加载表的两个坐标并按有理数嵌入实数。上面的实际ERM输出、报告加载及履行私有参数frame给出

\[
\Psi(\operatorname{episode}(s,a,Y))
=\left(Y,\theta/4+Y/2+1/8\right)
=\operatorname{after}(\Psi(s),Y).
\]

实际行动也不能被上式忽略。取原有相同币种、当事人和来源许可下的两个履行菜单：行动0实际给付1；行动1在同一次 Y=1 时实际给付2，Y=0 时给付0。原账户履行得到的 paid 增量恰为这笔金额，债的分配和超额余额各自继续保存。令 q 为当前实际加载表给出的响应概率，两种行动的同世界实际现金期望为

\[
V(s,0)=(1-q)\cdot1+q\cdot1=1,\qquad
V(s,1)=(1-q)\cdot0+q\cdot2=2q.
\]

两个期望用的是原共同分布 Ξ 的同一结果边际。已有合法菜单最大值定理选择它们中的最大值，并把所选行动真正写进原履行命令的金额载荷。q 穿过 1/2 时所选原命令改变；它不是与执行无关的评分。具体地，初态 z=(0,0) 先选行动0；同一次真实结果 Y=1 经过实际拟合、加载和付款，顺接后态 z′=(1,5/8)，q′=11/16，下一真实命令改选行动1。下一次选择读取这次原生拟合、报告留存、实际加载后的表。上式的数值学习投影不依赖所选行动，但完整现金与命令历史确实依赖它。

同一 Y 同时决定实际发生、样本标签、拟合分支、私人参数和所选命令下的现金。把完整 (a,Y) 日志每一项顺接到上一实际后态，可以重建全部原操作；任意有理初态和任意有限日志保持账户不变量。以原实例的同一 Ξ 边际抽取 Y，一步实际核经 Ψ 推前恰为原数值 K。这是一条已从实际后态逐点算出的交换式，不是新加的交换假设。

对该核交换式，原共同路径构造逐次运输整个“已有前缀、下一后态”的联合律，再由所有完整有限前缀确定整条路径律。因此实际自适应行动日志上的数值全路径及每个完整有限前缀一起运输到原数值过程，而非仅有各时刻边际相等。实际行动日志保持真实所选 a；它没有被改称原数值模型中未实际执行的独立公平行动日志。

该数值投影之外，完整法律后态及所有原命令仍在日志重放中；模型的辅助实数参数每一步从同一实际加载表写入。实际私人学习没有被另设一个与 CN 不相通的学习器替代。统计校准继续消费相同实际拟合表，并保留原协议、同表绑定、覆盖、支持及风险条件；单个样本零损失不替代原总体保证。

这一连接把原数值收缩定理用于这个实际法律/学习 episode 的投影。原不变测度的命题仍在原实数状态空间内；有理有限可达轨迹的嵌入不意味着不变测度支撑于有理点，也不要求其他法律制度全部收缩。
