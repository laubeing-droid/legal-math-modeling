### I.0.1 CAD的完整交付与确定依赖

#### I.0.1.1 检查器优先且完整生成器必交

采纳“检查器优先”的施工排序，撤回“完整算法形式化是后续增强”的降级建议。总交付仍必须包含以下三件：

1. `checkCAD φ cert ψ=true → ∀x, denote φ x ↔ denote ψ x`：独立检查器健全。
2. `buildCAD φ`对每个合格有限RCF输入终止；输出全分解和ψ。
3. `checkCAD φ (buildCAD φ).cert (buildCAD φ).ψ=true`：参考完整算法生成的证书必被接受，故检查器路径没有偷缩可完成域。

第1件完成可提前接入下游的已核实例，第2/3未完成时不能给整项“完整形式化交付”或“全范围可运行”的验收。数学上的可达性已有成熟构造；形式化工作量不能编造小时数，也不能用预算耗尽删输入域。

## I.3 公共类型具体怎么写

### I.3.1 复用与拟新增类型的分工

所有拟新增类型的字段遵循以下合同；名称最终可就近调整，法律含义和依赖不得变化。

| 类型 | 必须携带的数据 | 不得携带的“答案” |
|---|---|---|
| 拟 `CaseDomain` | 每案主体、争点、规则实例、证据及事件的有限标识域；单独声明数值变量维数 | 不能因支持某结论才将它放入论域 |
| 拟 `ScopedAtom` | 案件、主体、争点、阶段、命题类型、极性；主体键复用已有结构化编码 | 不能把同名字符串当全部身份；未证明不编码为否定 |
| 拟 `NormBody` | 有类型前提／结论、模态、例外、优先条件、负担规则、后果表达式 | 不含最终裁判或总正确性证明 |
| 拟 `VersionedNorm` | 现有版本记录、规范内容、法域／范围、事实时间适用条件、来源标识 | 不以版本号代替规范内容 |
| 拟 `NormEnvironment` | `VersionedNorm` 的有限目录与内容解析关系 | 不允许与后端另存一份独立规范集 |

### I.6.1 两处必须先修的具体算法／证明强度问题

**P13：现有 PAV 不是已经证明的全序列最优器。** `pavGo` 在遇到首对不违反时把首块输出，后面合并可能使新均值低于已经输出的前块。合成等权序列 `[3,4,0]` 是应先形式化的检查目标：前块 3 被保留，后两块合并为 2，输出仍下降。施工写栈式算法：压入新块→相邻违反就合并并继续向前检查；以剩余输入和块数的良基度量证明终止，维护连续分块、总权重／标签和、块均值和有序性，最后由分块最优条件证明全局损失最小。现有两点完成平方证明可复用，但不能覆盖整个列表。

**N09／E01：不能把目标不等式换写后作为已有推导。** 本仓确有 `JurisLean.ULM.banach_exists_fixedPoint`、`banach_fixedPoint_unique`、`banach_iterates_converge`、`banach_apriori_error_bound`，可省去重证 Banach；新任务是把真实算子接入其 `ContractingWith` 前提。相反 `E01Contract.cantelli_core` 直接收进 `m*(σ²+a²)≤σ²`，仅作除法改写；真正统计界必须从独立概率对象、矩或原定假设推出该不等式，否则 E01 不闭合。

## I.8 七个根分别怎样成为真根

拟新增部门法签名采用共同语义的索引化规则，而不是三个不相干的总模型：

```lean
-- 拟：同一 Γ/c，按适用域选择规则；具体政策是具名法律语法实例。
def runDomain : DomainPolicy → LawContext → CaseInput → LegalResultRep
def DomainDerives : DomainPolicy → LawContext → CaseInput → LegalOutcome → Prop
theorem domain_run_exact (h : DomainInputWF p Γ c) :
    denotesLegal (runDomain p Γ c) = {o | DomainDerives p Γ c o}

    DomainDerives p Γ c o → LegalDerives Γ c o
```

### I.11.2 每一条一般定理的实际证明顺序

1. 先在独立语义处固定目标类型、输入域和法律依据，明确成功／失败／多解含义。
2. 写最直接的可执行构造：有限列表、Finset、结构递归、既有数值或符号算法，不先写总“证明记录”。
3. 将复用引理实例化到真正输入；补编码、作用域、来源、类型与单位转换的必要桥。
4. 健全性对计算步骤归纳；完备性对独立推导、有限候选域或符号消元归纳。两边都需要时分别写，不能用“sound”名字包含完整性暗示。
5. 证明空性／未决／不适用／缺输入分支的准确含义；证据不足不冒充本体为假。
6. 把该函数真正接入下一层；证明共享中间结果上的组合定理，以及该法律关系要求的非干扰或有效差异见证。
