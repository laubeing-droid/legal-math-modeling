## 1. 模型是什么：一句话定义

统一法律数学模型是一个**有制度解释的法律历史模型**：从同一组有来源的制度规则、事实材料与已声明的解释出发，构造法律关系、证据论证、裁判允许集合、行为与事件、法律效果与救济回流。概率是这些历史上的测度，策略是依可见历史选择行动的规则，金额是同一法律后果的数量投影。

"统一"的含义（Owner 2026-09-29 裁决钦定）：**理论统一**——从统一数学概念逐步推导整个法律的工作机制（法律概念→本体→规范运算→推理→概率→博弈行为→制裁后果→运行闭环），时间与不确定性两横切贯穿。工程接线（接口/CI/桥）只是实现手段，永远不定义统一本身。

## 2. 共同数学基础（§2 已实现：Python 载体层）

一份制度呈现 `I=(Σ,N,A,C,O)`：多类签名 Σ（主体/客体/行为/事件/时点/法域/机关/来源）、具名规则有限呈现 N（可含循环）、制度承认的机关职权 A、关系间法律共同约束 C（同一损失上限/竞合/共同清偿/不能并存的处分）、可观察材料的产生与准入规则 O。

三类分离的实际载体（已实现，`theory/spec/canonical_v2/case.py`）：

| 对象 | 载体 | 分离要点 |
|---|---|---|
| 实际世界 R | `ProcessState.r`（NormState） | 裁判路径**不读取**（judgment_noninterference 已测） |
| 材料/评价历史 E | `EvidenceRecord`（带 produced_at/known_at） | 可见投影 `visible_evidence(cutoff)` 按 as_of 截断 |
| 认知状态 K | 由可见 E 经独立推导**重建**，不存储 | 输入良构禁止预填最终答案 |

`ScopedAtom`（案件/主体/争点/阶段/谓词/极性）是全部原子键的纪律：同名不同主体/争点不合并；claim 键经长度前缀+极性前置+"~"归一实现防碰撞编码（第三轮审查修复 N1/E）。

## 3. 规范运算（§3 已实现：Python 全解构造 + Lean 层A/B 定理）

### 3.1 稳定选择（§3.1 排除图全解）

**定义**（Lean `StableSelection`，四合取支）：
```
S ⊆ C ∧ (∀a,b∈S, ¬D(a,b)) ∧ (∀n∈C\S, ∃s∈S, D(s,n)) ∧ (报请对禁同采)
```

**已证定理**（Lean，全部带 CI 证据，subject 0191909）：

| 定理 | 内容 | 证据 |
|---|---|---|
| `isolated_in_every_stable_selection` | 无入边的孤立候选必入每稳定选择——**全域极大筛选不是算法**的形式化根据 | 模块 CI 37742569198；全量 37752300043 |
| `escalation_only_has_no_stable_selection` | 仅报请冲突无稳定选择——报请而非捏造选择 | 同上 |
| `abc_stable_AC` / `abc_A_alone_unstable` | A>B>C 见证对：{A,C} 稳定、{A} 不稳定 | 同上 |
| `enumerateStable` + `mem_enumerateStable_iff` | **全解构造健全+完备双侧定理**：S ∈ 全幂集过滤族 ↔ S 稳定；枚举不发明候选 | 模块 CI 37759613136；全量 37763557999 |

Python 对应（`unified/norm_selection.py`）：`enumerate_stable_selections` 穷举全子集（fail-closed 预算 20），同位授权双向边保双解，排除环报 NORM_CONFLICT。反例测试钉死 A>B>C。

## 4. 论证、攻击与扩展（§4 已实现：Python 文法层）

- **正则树文法**（`unified/argument_grammar.py`）：有限产生式表示**全部**良构有限论证树——有根循环语言无限而摘要有限（有根 p⇒p：2 摘要 vs 无限嵌套），无根循环语言空（不凭循环制造依据）。
- **有限摘要 Q**：`(head, sites)` 观察等价；默认 Last 策略（叶∅/可废止根{j}/严格根并）。
- **七类攻击**：rebut/undermine 受 Stronger 偏好阻断，其余五类（undercut/exception/authority/scope/procedure）不读偏好；BlockedUse/GateBlocked 原子承载。反例测试逐类钉死字段依赖。
- **四扩展精确回拉**：grounded 有限迭代、complete/preferred/stable 全幂集枚举；自攻 stable 空族 ≠ {∅} 族（分型测试钉死）；3-环 preferred={∅}。
- 因子化定理 `Defeat(a,b) ↔ D(q(a),q(b))` 以有限树枚举暴力验证（一般证明为 Lean 层 C 义务）。

## 5. 证据标准与裁判（§5 已实现：Python 证书层）

- **具名充分性模板**（`StrongTemplate`，环境载体）是 StrongBasis 的**唯一**来源：前提谓词+具名败因（已获准事件阻断）+许可规则（受规范选择门控）。案件输入**无法**携带结论谓词或强度（第二轮审查修复的后门关闭，篡改测试验证）。
- **特别认定通道**（自认/免证/终局拘束/举证妨碍）独立直入 E(q)，不 confer StrongBasis。
- **CivilHigh** := In 强依据 ∧ 无 Live 实质反证；实质反证由 W-MATERIAL（直接支持∧决定性∧(佐证∨决定性矛盾)）生成，裸否认不生成。同身份反角色（Strong(¬p,s)≡MaterialCounter(p,s)）。
- **终结表**六型：POS/NEG_BLOCKED/NEG_BURDEN/LEGALLY_UNDETERMINED/NOT_READY/GAP——依法未决须 Exhausted4∧Need，未提交**被引用**材料延迟负担（无关文件不延迟）；200 次暴力检查无同扩展双 CivilHigh。
- **反证极性**：败因=已获准事件（ADMITTED_POSITIVE+polar POS）；明确否定=正常贷款情形，不阻断。
- **Lean 层D（准入与负担的证明面）**：`Seams/UnifiedAdmission.lean`——具名依据六通道（普通支持/推定/免证/自认/终局拘束/举证妨碍），依据有效=前提全采纳∧阻断全未采纳；U08 `accepted_has_legal_basis`（n 轮后采纳的每件事实都锚定在某轮有效依据的许可面）；U09 负担双定理（负担失败只落在 pending 争点；负担失败与事项真实相容——非本体否定）；U10 `admission_reaches_fixed_point`（预算内步数非严格增则达不动点，采纳集有界）。模块 CI 绿（run 37792655115，subject 6cd2c65）。
