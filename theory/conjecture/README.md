# Conjecture Modules

This directory contains exploratory executable hypotheses that have not been promoted into the formal release surface.

`kolmogorov_mdl_rules.py` studies an MDL/Kolmogorov-inspired rule-selection hypothesis. Its code and tests may provide finite or empirical evidence, but the directory name is literal: results remain conjectural unless a separately named theorem or verified certificate closes the exact claim.

Do not cite a conjecture module as Lean proof, legal authority, empirical calibration, or production validation. Counterexamples and inconclusive results must be retained rather than normalized into PASS.
